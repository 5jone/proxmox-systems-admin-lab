Project Evolution

From hypervisor administration to cloud engineering

Phase 0: CORP-DC01 and CORP-DC02 were built and validated on Proxmox VE. The work proved AD DS, DNS, replication, SYSVOL/NETLOGON, Windows time, troubleshooting, and recovery fundamentals.

Phase 1: The environment is being rebuilt cleanly in Azure. The goal is not a lift-and-shift of VM disks; it is a cloud redesign that adds segmentation, secure private administration, governance, monitoring, backup, cost controls, and Infrastructure as Code.

Azure Architecture

Private, segmented, and built for operational proof
