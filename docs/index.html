Overview

Built to be explained, tested, and defended

The lab is designed around operational proof rather than role installation alone. A component is not treated as complete until its configuration, behavior, and recovery path can be validated and explained.

The repository is the evidence layer: build logs, inventory, screenshots, scripts, validation results, and commit history. This site is the interview-facing presentation layer.

Troubleshooting & Recovery

A real servicing failure became part of the evidence

Symptom

Windows Server stalled during a servicing restart while stopping the Update Orchestrator Service.

Investigation

Proxmox task history showed a reboot timeout and later power actions failing because the VM lock was still held.

Recovery

After the original task released, the guest was recovered with the noVNC Hard Stop action and Windows servicing was allowed to complete.

Improvement

Observed memory pressure informed an evidence-based resize from the original conservative 4 GiB baseline to 8 GiB fixed memory before AD DS promotion.
